## What is implemented

The legacy three-player random/random+TAG input boundary remains explicit. A
separate six-player parser accepts check-call only. It reconstructs public
histories using hero cards and a fresh compatible joint deck, retaining every
opponent's card removal. Policies receive only their acting-seat observations.
Every legal root action branches independently, then follows the unchanged
blueprint and scripts. Missing/zero-mass fallback and policy RNG semantics stay
with the existing reader/Policy implementation.

The native example loads one shared read-only live-order average. Mature cost
calibration binds the binary, checkpoint, source average and embedded mass
receipt. It independently reconstructs archived keys, preserves menu order,
reports support, and compares float64 action values and work counts across
identical repeated worlds. Main mode currently refuses execution pending review
and measured admission; the qualification command cannot launch it.

The streaming extractor samples36 declared seat/street/action strata without
using rewards, original opponent cards or future outcomes. It bounds memory by
retaining37 distinct-block candidates per stratum while preserving the exact
greedy priority selection. Full counts and missing strata are retained. It
supports the existing gzip traces, verifies compressed and uncompressed hashes,
and distinguishes original legacy verification receipts from independent replay.
Those receipt types must not be described interchangeably.

PR431's trace header names the common game through the history-key control.
The focal pin identifies live-order. The new native code checks that focal
schema directly; merely trusting the common header would refuse these inputs.
